## Share feedback

[Report a bug or suggest an improvement](https://github.com/sshilal1/cosmic-court-updates/issues/new/choose).

Open issues are the feedback queue. Completed issues are closed with a completion date and a link to the release that delivered them. Questions stay open until answered or a decision is recorded. Reading releases needs no account; posting feedback requires a GitHub account.

Please describe what happened, what you expected, and whether you were on a phone or computer. Keep account recovery keys, sign-in links, email addresses, and other private information out of public issues. Private account problems can use the game's Feedback page.

This repository contains player updates and feedback. The playable game is at [cosmic.shillex.us](https://cosmic.shillex.us).
